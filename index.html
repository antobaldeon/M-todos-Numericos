Raíces de ecuaciones no lineales

Aplicación de métodos cuantitativos cerrados (como bisección y falsa posición) y abiertos (punto fijo, Newton-Raphson y secante) para resolver ecuaciones en ingeniería, incluyendo una herramienta configurable para el análisis de funciones arbitrarias.

Dimensionamiento de un enlace de red

Bisección

Capacidad mínima C (Mbps) que anula el tiempo de espera promedio de los paquetes en cola (modelo M/M/1 simplificado).

f(C) = 1 / (C − 8.5) − 0.35·ln(C − 2) = 0
function f(C) {
  return 1 / (C - 8.5) - 0.35 * Math.log(C - 2);
}

function biseccion(f, a, b, tol, maxIter) {
  let xrAnt = null;
  for (let i = 1; i <= maxIter; i++) {
    const xr = (a + b) / 2;
    const fxr = f(xr);
    const err = xrAnt === null ? null : Math.abs((xr - xrAnt) / xr) * 100;
    // registrar fila: i, a, b, xr, fxr, err
    if (fxr === 0 || (err !== null && err <= tol)) break;
    if (f(a) * fxr < 0) b = xr; else a = xr;
    xrAnt = xr;
  }
}

Migración de un sistema a la nube

Falsa Posición

Tiempo t (años) en que el costo acumulado on-premise se iguala al costo acumulado en la nube.

f(t) = 45 + 12t − 20·e^(0.4t) = 0
function f(t) {
  return 45 + 12 * t - 20 * Math.exp(0.4 * t);
}

function falsaPosicion(f, a, b, tol, maxIter) {
  let xrAnt = null;
  for (let i = 1; i <= maxIter; i++) {
    const fa = f(a), fb = f(b);
    const xr = b - fb * (a - b) / (fa - fb);
    const fxr = f(xr);
    const err = xrAnt === null ? null : Math.abs((xr - xrAnt) / xr) * 100;
    if (fxr === 0 || (err !== null && err <= tol)) break;
    if (fa * fxr < 0) b = xr; else a = xr;
    xrAnt = xr;
  }
}

Temperatura de equilibrio en un centro de datos

Punto Fijo

Un centro de datos debe mantener la temperatura de una sala de servidores en equilibrio. Se resuelve directamente con la forma de iteración T = g(T).

g(T) = 18 + 8·e^(−0.15T)  |  T₀ = 20
function g(T) {
  return 18 + 8 * Math.exp(-0.15 * T);
}

function puntoFijo(g, f, x0, tol, maxIter) {
  let xPrev = x0;
  for (let i = 1; i <= maxIter; i++) {
    const x = g(xPrev);
    const err = i === 1 ? null : Math.abs((x - xPrev) / x) * 100;
    if (err !== null && err <= tol) break;
    xPrev = x;
  }
}

Tiempo de respuesta de un sistema

Newton-Raphson

Raíz positiva del modelo cúbico de tiempo de respuesta de un sistema (t en milisegundos), usando la derivada de f.

f(t) = t³ − 7t − 5 = 0  |  f′(t) = 3t² − 7
function f(t)  { return t**3 - 7*t - 5; }
function df(t) { return 3*t**2 - 7; }

function newtonRaphson(f, df, x0, tol, maxIter) {
  let xPrev = x0;
  for (let i = 1; i <= maxIter; i++) {
    const x = xPrev - f(xPrev) / df(xPrev);
    const err = Math.abs((x - xPrev) / x) * 100;
    if (err <= tol) break;
    xPrev = x;
  }
}

Punto de operación de un módulo de software

Secante

Raíz obtenida sin derivar la función, usando dos aproximaciones iniciales x₀ y x₁.

f(x) = e^(−x) − x² + 0.2 = 0
function f(x) { return Math.exp(-x) - x**2 + 0.2; }

function secante(f, x0, x1, tol, maxIter) {
  let prev = x0, curr = x1;
  for (let i = 1; i <= maxIter; i++) {
    const fPrev = f(prev), fCurr = f(curr);
    const x = curr - fCurr * (curr - prev) / (fCurr - fPrev);
    const err = Math.abs((x - curr) / x) * 100;
    if (err <= tol) break;
    prev = curr; curr = x;
  }
}
